VelocityDRIVE-SP-2025.09 Release Notes

1. 2025.09

Version:            2025.09
Previous Version:   2025.06     (yyyy.mm-cnt)
Release date:       2025-09-26  (yyyy-mm-dd)
Type:               Roadmap release
YANG Catalog SHA:   70a9c09e5a0a0382f5de262c9db2db4d

1.1. New PTP Instance types and features

The PTP implementation has been updated with the following new features:

  1. Peer to peer (P2P) Transparent clock (TC) supporting 1-step and 2-step. See this section for more details on how to configure it.

  2. End to end (E2E) Transparent clock (TC) supporting 1-step and 2-step. See this section for more details on how to configure it.

  3. Support for PTP over a PRP interface. The support here is limited to 3-way boundary clock (TWBC). No configuration is needed. If a redbox is enabled on a given interface then this mode is activated.

1.2. New Management Attributes

  1. PTP: A new YANG leaf: disable-hw-calibration, has been added. This can be used to disable calibration data from the board-configuration files. This is necessary if re-calibration is required the board. See this section for more details on calibration.

  2. A new YANG leaf called mode, has been added in the single-leaky-bucket container. This can be used to configure whether the shaper should use line rate or data rate.

  3. A new YANG leaf called mode has been added in the credit-based container. This can be used to configure whether the shaper should use line rate or data rate.
